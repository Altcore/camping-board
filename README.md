# Кемпинг × настольные игры

Статическое приложение для публикации на Vercel. Состояние хранится в одной строке Supabase и синхронизируется через Realtime.

## 1. Настройка Supabase
1. Откройте Supabase → SQL Editor → New query.
2. Скопируйте весь файл `supabase.sql`, нажмите Run.
3. Откройте Project Settings → API (или Data API).
4. Скопируйте Project URL и Publishable key (или legacy anon key).
5. В файле `config.js` замените два значения-заглушки на скопированные значения. Кавычки оставьте.

Важно: используйте только Publishable/anon key. Никогда не вставляйте `service_role` или secret key в браузерный проект.

## 2. Публикация через GitHub и Vercel
1. Создайте новый репозиторий на GitHub (например, `camping-board`).
2. Загрузите в корень репозитория файлы `index.html` и `config.js`. Файл `supabase.sql` можно оставить там же для справки.
3. На Vercel нажмите Add New → Project.
4. Импортируйте репозиторий GitHub.
5. Framework Preset: Other. Build Command и Output Directory оставьте пустыми (или укажите `.` для Output Directory).
6. Нажмите Deploy. Vercel выдаст публичную ссылку.

## 3. Проверка
Откройте ссылку в двух разных браузерах или на двух телефонах. Измените имя или отметку в одном окне — она должна появиться в другом через несколько секунд.

## Доступ и безопасность
Сейчас это общая открытая доска без входа: любой, у кого есть URL приложения, может читать и менять состояние. Не храните здесь личные или чувствительные данные. Для закрытой компании можно позже добавить пароль комнаты или авторизацию.
